# 04_lvgl_arduino_v8

[English](README.md) | [简体中文](README_ZH.md)

## What It Does

This example demonstrates 04_lvgl_arduino_v8 on the ESP32-C6-Touch-LCD-1.47 board.

## Hardware Required

- ESP32-C6-Touch-LCD-1.47 development board

## How to Run

1. Install Arduino-ESP32 3.3.10.
2. Set the sketchbook location to `examples/arduino/`, or copy `examples/arduino/libraries/` into your sketchbook libraries folder.
3. Select `ESP32C6 Dev Module`, USB CDC On Boot `Enabled`, Flash Size `4MB`, Partition Scheme `Default 4MB with spiffs`, and CPU Frequency `160MHz`.
4. Open the sketch and upload.

## Expected Result

The example output is shown on the LCD or serial monitor according to its function.
