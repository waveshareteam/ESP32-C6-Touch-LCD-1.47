# 04_lvgl_image

[English](README.md) | [简体中文](README_ZH.md)

## What It Does

This example initializes the LCD and displays the bundled image through LVGL.

## Hardware Required

- ESP32-C6-Touch-LCD-1.47 development board

## How to Run

```bash
idf.py set-target esp32c6 build flash monitor
```

## Expected Result

The LCD displays the bundled image.
